Bem-vindo ao repositório do **Frontline**, um projeto full-stack desenvolvido como um clone do Twitter. O objetivo desta aplicação é recriar a experiência de uma rede social moderna, focada no compartilhamento de conteúdo e interações entre usuários.

**BACK-END** : **[KueRocha](https://github.com/KueRocha)** -
**FRONT-END** : **[JVPradoDev](https://github.com/JVPradoDev)**

## 📋 Sobre o Projeto

O Frontline oferece uma experiência completa de rede social com as seguintes funcionalidades:

- **Gestão de Usuários:** Criação de novas contas de usuário e edição de perfil completa (alteração de foto de perfil, nome de exibição e senha).
- **Conexões:** Sistema de busca para encontrar outros usuários e funcionalidade para seguir perfis.
- **Feed e Publicações:** Criação de posts em texto e visualização de um feed baseado nos usuários que você segue.
- **Engajamento:** Capacidade de criar comentários dentro dos posts, além de poder curtir tanto os posts quanto os comentários de outros usuários.

## 🚀 Tecnologias Utilizadas

O projeto foi dividido em duas partes principais, utilizando tecnologias modernas para garantir performance e escalabilidade:

### Front-end
- **[React](https://reactjs.org/)** - Biblioteca JavaScript para construção da interface.
- **[Vite](https://vitejs.dev/)** - Ferramenta de build rápida.
- **[TypeScript](https://www.typescriptlang.org/)** - Tipagem estática para maior segurança no código.

### Back-end e Banco de Dados
- **[Django](https://www.djangoproject.com/)** - Framework web robusto em Python.
- **[Django REST Framework](https://www.django-rest-framework.org/)** - Utilizado para a construção e gerenciamento da API RESTful.
- **[PostgreSQL](https://www.postgresql.org/) via [Supabase](https://supabase.com/)** - Banco de dados relacional poderoso hospedado na nuvem.
